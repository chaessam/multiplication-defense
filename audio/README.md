# 음원 파일 넣는 곳 (선택)

이 폴더가 비어 있으면 게임이 **Web Audio로 직접 합성한 음악/효과음**을 씁니다.
더 좋은 소리를 원하면 아래 이름으로 음원 파일(`.mp3`, `.ogg`, `.wav` 중 하나)을 넣으세요.
있는 파일만 바꿔 쓰고, 없는 소리는 합성음이 그대로 나옵니다.

> 주의: 브라우저 보안 때문에 `index.html`을 파일로 직접 열면(file://) 음원을 못 읽어요.
> GitHub Pages / Cloudflare 같은 주소로 열 때만 적용됩니다.

## 배경 음악 (반복 재생)

| 파일 이름 | 쓰이는 곳 |
|---|---|
| `bgm_title` | 처음 화면 |
| `bgm_prep` | 웨이브 사이 준비 시간 |
| `bgm_battle` | 전투 중 |
| `bgm_boss` | 보스 등장 |

## 효과음

`correct` 정답 · `wrong` 오답 · `arrow` 화살 · `bolt` 영웅 석궁 · `cannon` 대포 · `boom` 폭발 · `frost` 얼음 ·
`hit` 명중 · `die` 적 쓰러짐 · `gem` 보석 · `castleHit` 성 피격 · `build` 건설 · `coin` 동전 ·
`upgrade` 강화 · `evolve` 진화 · `horn` 웨이브 시작 나팔 · `boss` 보스 · `victory` 승리 · `lose` 패배 ·
`skill` 스킬 · `ult` 필살기 · `card` 카드 · `pick` 카드 선택 · `star` 별 · `achieve` 업적 · `cut` 보스 컷인 · `key` 숫자 입력

예: `audio/bgm_battle.mp3`, `audio/correct.ogg`

## 무료로 쓸 수 있는 음원 추천 (저작권 표시 없이 쓸 수 있는 CC0 위주)

- Kenney (kenney.nl) — RPG Audio, Interface Sounds, Impact Sounds 등 (CC0)
- OpenGameArt (opengameart.org) — "medieval", "fantasy" 로 검색, 라이선스가 CC0인 것을 고르세요
- 그 밖의 음원은 라이선스(상업적 사용, 출처 표기)를 꼭 확인하세요.
