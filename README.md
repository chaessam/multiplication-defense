# 🏰 구구단 디펜스 (Multiplication Defense)

모바일 게임 킹샷(Kingshot) 느낌의 **로우폴리 3D 타워 디펜스 + 구구단** 웹 게임입니다.
설치 없이 휴대폰·PC 브라우저에서 바로 즐길 수 있어요.

## 플레이 방법

- 구불구불한 길을 따라 성으로 몰려오는 적 머리 위의 문제(예: `7 × 8`)의 답을 입력하면 성에서 번개가 떨어지고 **골드**를 얻습니다.
  - 숫자판(모바일) 또는 키보드(PC)로 입력합니다. 답이 확정되면 자동으로 제출돼요.
  - 같은 답을 가진 적이 여럿이면 성에 가장 가까운 적부터 맞습니다.
  - 연속으로 맞히면 콤보 보너스 골드를 받아요.
- 길 옆 점선 칸(+)을 눌러 **궁수탑 / 대포 / 서리 마법탑**을 세우면 자동으로 적을 공격합니다.
- 적을 쓰러뜨리면 **보석**을 얻습니다. 보석으로 🔧 성 수리, ❄️ 얼음 폭풍, ☄️ 유성 낙하 스킬을 쓸 수 있어요.
- **⚒ 강화**에서 골드로 성벽(최대 체력), 궁수·대포·마법 공격력, 공격 속도, 현상금(정답 골드)을 올립니다.
- 적이 성에 닿으면 성 체력이 줄고, 0이 되면 게임 오버입니다.

### 웨이브

- 웨이브가 오를수록 적이 많아지고 빨라지며, 2단부터 시작해 점점 어려운 단이 나옵니다 (9웨이브부터 2~9단 전체).
- 적 종류: 병사 → 고블린(빠름) → 기사(튼튼함) → 오우거·트롤(문제를 2~3번 맞혀야 함)
- **5웨이브마다 보스**: 오크 대족장 → 붉은 드래곤 → 해골 마왕 (문제를 여러 번 맞혀야 쓰러짐)

### 저장 / 이어하기

- 웨이브가 시작되기 전 상태가 이 기기의 브라우저(localStorage)에 자동 저장됩니다.
- 처음 화면에서 **이어하기**를 누르면 마지막으로 진행하던 웨이브부터, **새 게임**을 누르면 처음부터 시작해요.
- 게임 오버가 되어도 마지막 웨이브부터 다시 도전할 수 있습니다.

### PC 단축키

| 키 | 동작 |
|---|---|
| `0`~`9` | 답 입력 |
| `Enter` | 제출 |
| `Backspace` | 지우기 |
| `Space` | 웨이브 시작 / 2배속 전환 |
| `Esc` | 일시정지 |

## 실행하기

빌드 과정이 없는 순수 HTML/CSS/JavaScript입니다.

- `index.html`을 브라우저로 바로 열거나,
- GitHub Pages로 배포하면(저장소 Settings → Pages → 브랜치 선택) 휴대폰에서도 주소로 접속해 플레이할 수 있어요.

- 3D 그래픽은 [Three.js](https://threejs.org) (r158, `js/vendor/three.min.js`에 포함)로 지형·성·탑·병사·보스를 로우폴리 모델로 직접 만들어 그립니다. 별도 이미지·3D 모델 파일이 필요 없어요.
- 가로 화면(PC)에서는 성이 오른쪽, 적이 왼쪽에서 오고, 세로 화면(휴대폰)에서는 킹샷처럼 성이 위쪽, 적이 아래쪽에서 올라옵니다.
- 배경 음악과 효과음은 Web Audio API로 실시간 합성합니다. (글꼴만 Google Fonts에서 불러오며, 오프라인이면 기본 글꼴로 표시됩니다.)

## 파일 구조

```
index.html             화면 구성
css/style.css          모바일 게임풍 UI 스타일, 모바일/PC 반응형 레이아웃
js/vendor/three.min.js Three.js 3D 라이브러리
js/world.js            3D 월드: 지형·길·성·탑·적/보스 모델·투사체·파티클·카메라
js/audio.js            BGM(중세 도리안 선율, 류트, 드럼)과 효과음 합성
js/game.js             게임 로직(웨이브, 문제, 탑, 강화, 스킬, 저장)과 문제 말풍선 표시
```
